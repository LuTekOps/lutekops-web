# lutekops.ch

Statische Website von LuTekOps, ausgeliefert über GitHub Pages (Custom Domain `lutekops.ch`, siehe `CNAME`).

- `index.html` – Startseite, `impressum/` – Impressum & Datenschutz, `404.html`
- `assets/site.css`, `assets/site.js` – Styles und kleine Effekte (keine externen Requests, strenge CSP)
- `assets/fonts/` – Space Grotesk, Inter, JetBrains Mono (SIL OFL, Lizenzen daneben)
- `assets/video/picker-tiktok-de.mp4` – Picker-Promo, 720p H.264, faststart

Lokal ansehen: `python3 -m http.server` und http://localhost:8000 öffnen.
